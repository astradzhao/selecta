# DJ Graph Notes

DJ-helping note-taking app: natural-language mix notes → Neo4j graph → live “what’s next” UX.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Deploy target: Vercel

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```
