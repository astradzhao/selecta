Notes — Transitions

  1. The pair is the row. Today the row is one sentence — “Title A → Title B” with the artists in a second sentence — so neither song is legible at a glance. Two mirrored track cells with artwork make the edge scannable, and the arrow becomes an object in its own column instead of a character inside a paragraph.
  2. Match is the signature column. BPM and key on both sides is what a DJ checks before trusting an edge, and no other list in the product can show it. Same value / value discipline as the Tracks tab: the slot stays visible with an em dash when a side is unknown.
  3. Needs review sits inside the workbench, not above it. The queue keeps the exact pair geometry of committed rows (dashed border, warning arrow, source quote underneath), so reviewing is a comparison, not a context switch. An unresolved endpoint renders as a dashed tile plus the phrase from the note — the reason review exists. On All it pins to the top of the list, on Needs review it is the whole list, and on Confirmed it disappears.
  4. Two fields and one dropdown. The toolbar becomes From track → To track → state, so the filter shape is the row shape. Technique, Intent, and Source are gone: nobody arrives at this page wanting “every transition tagged echo out”, and Source (manual vs. from submission) was a data-provenance question wearing a filter costume. State answers the question people actually have — All, Confirmed, Needs review — and it replaces the “Needs review only” checkbox, which was a second, weaker control saying the same thing.
  5. Mix collapses technique and intent into one column. Filled chip = technique, outline chip = intent. Both are already on the list payload, and they stay readable in the row even though they are no longer filterable.
  6. Needs an API change. GET /transitions serializes endpoints as { id, title, artists } only. Artwork, BPM, and key are already loaded on TransitionRecord.from.track / .to.track — this is a serializer widening in apps/api/lib/transitions.ts, not a new query.
  7. Everything else is composition. Row height 60px (slightly taller than the 56px crate row, because two artworks and a two-line match cell share it), one bordered card, count moved to the card footer next to Load more.
