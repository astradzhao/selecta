Notes — Add transition

  1. This is not New submission. The Transitions “Add transition” button currently opens the LLM note form. This page writes one transitions row and never creates a submission. Dumping a paragraph of mixes still happens on New submission.
  2. One search per side, two sources. Library hits sit first. Catalog hits sit under their own group and stay pending until submit — the blue chip is a promise, not an import. Tabs (Suggested / Library / Catalog) are for proposal review, where the model already guessed; they are extra chrome here.
  3. Quality is a closed enum. Technique and intent are not. Ranking sorts on great / ok / risky — three values, so a segmented control shows the whole enum and costs one click instead of two. Technique and intent suggest the known vocabulary (High-pass filter, Cut, Build hype…) but you can keep typing a custom mix. The open list in the mock is that combobox.
  4. Swap is not reverse. It exchanges the two endpoints of this one edge. There is no “also create B → A” checkbox — bars and a mix that works one way are not symmetric.
  5. Bars live on the songs they belong to, and read as a sentence. Each box is only as wide as the number it holds, carries its own unit, and is labelled by what it does: Cut out at 64 bar under the outgoing track, Overlap 16 bars on the seam, Come in at 1 bar under the incoming one. They still map to fromBar / overlapBars / toBar. Technique, intent, quality, and notes are the mix itself, so they sit in a second block under a Mix label, not in the same grid as the tracks.
  6. An empty side is the search field. Both slots are the same height with the same artwork square; the empty one is dashed and its square holds a magnifier, so there is no input box floating inside a card. Hits drop as a popover anchored to the slot, so picking a song never shoves the bar row around. Every control on the page — search, bar boxes, comboboxes, quality, buttons — is one height.
  7. Create stays disabled until To is picked (and never if both sides resolve to the same track). Cancel and the back link return to the Library tab that opened this page.
