Notes

  1. The add button gets a home. A page-level action belongs opposite the page title, not stacked between the tabs and the filters. It stops competing with the list and stops looking like a third navigation layer.
  2. Five bands become two. Filters, column header, and rows share one border, so the page reads as a masthead plus a workbench.
  3. The subtitle carries facts, not instructions. "Search your tracks or narrow the list by Subgenre and Folder" described the controls directly beneath it. Counts are more useful, and dead ends is the number worth acting on.
  4. Transitions is the signature column. It is the one thing here that no other music library could show. Needs the list endpoint to return an outbound count — everything else on this page ships with no API change.
  5. BPM and key stay as columns even though they are mostly empty. Neither is populated from the catalog, so the header does the work of showing what could be filled in. If that reads as too aspirational, the column can collapse until one track has a value.
  6. Rows go 72px to 56px. Denser is more faithful to DJ software and puts more of the crate on screen; column labels make the numeric rail readable.
